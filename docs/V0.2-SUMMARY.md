# V0.2 技术文档

v0.2 加了 Ollama 本地模型支持和翻译缓存。没有新文件结构上的大变化，主要是在 `translator.ts` 加实现类、新增 `cache.ts`。

## 新增功能

### Ollama 本地模型

`OllamaTranslator` 走 Ollama 的 `/api/chat` 接口，和 OpenAI 用同一套系统 prompt。和 OpenAI 的区别：

- 支持 HTTP（本地服务，`http://localhost:11434`），所以请求函数要同时处理 http 和 https。
- 响应格式不同：Ollama 的结果在 `data.message.content`，OpenAI 在 `data.choices[0].message.content`。
- 错误提示做了本地化：连不上时提示 `ollama serve` 是否启动；模型不存在时提示 `ollama pull`。

配置项 `ipynbTranslator.ollama.endpoint` 和 `.model`，默认 `llama3`。

### 翻译缓存

`src/cache.ts` 的 `TranslationCache`。相同内容不重复请求 API，省 Token。

实现：

- 缓存键是原文的 MD5，值是译文，存在 `context.workspaceState` 的 `translation_cache_v1` 下。
- 按工作区隔离，VSCode 重启后还在。
- 接口：`get(text)`、`put(text, translation)`、`clear()`、`size`。

一个语义注意点（v0.3 之后才暴露）：bilingual 模式下，翻译过的单元格会含中文，二次运行时 `hasChinese` 先命中、跳过，缓存根本不会复用同一个单元格。缓存只对"同一段英文出现在多个单元格"有用。v0.4 没改这个，因为它不是 bug，是 bilingual 模式的预期行为。
