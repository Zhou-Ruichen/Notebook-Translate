# V0.3 技术文档：Profile 系统与密钥隔离

v0.3 把扁平配置（`ipynbTranslator.openai.apiKey` 这种）改成多 Profile 系统，密钥从 `settings.json` 移到系统钥匙串，加了状态栏交互和推理模型的思维链清洗。

## Profile 系统

`ProfileManager`（`src/profileManager.ts`）管理多套翻译配置。配置分两层存：

- `settings.json` 只放公开元数据：`name`、`provider`、`model`、`baseUrl`/`endpoint`、`appId`、`customPrompt`。
- 密钥（`apiKey`、`secretKey`）经 VSCode SecretStorage 存到系统钥匙串，不进配置文件。

接口：`getProfiles`、`getActiveProfile`、`setActiveProfile`、`addProfile`、`updateProfile`、`deleteProfile`、`getApiKey`、`setApiKey`、`deleteApiKey`、`rollbackToPrevious`。保存前 `stripKeys` 清掉 profile 对象上的密钥字段，确保不泄漏到 `settings.json`。

切换 Profile 时存一份 `previousProfileName` 到 `globalState`，测连失败时 `rollbackToPrevious` 回退。

## 密钥迁移

启动时 `migrateLegacyKeys` 扫描旧配置：如果 profile 对象上还带着明文 `apiKey` 或 `secretKey`，搬进 SecretStorage，从配置里删掉。`migration.ts` 处理更早的 v0.1/v0.2 扁平配置（`ipynbTranslator.openai.apiKey`）到 Profile 系统的一次性迁移。

## 推理模型支持

DeepSeek R1 这类模型会在正文前输出 `<think>…</think>` 思维链。`cleanThinkTags` 用正则 `<think>[\s\S]*?<\/think>` 剥掉。剥完如果为空（模型只输出了思考过程），抛 `Translation Empty (Reasoning only)`，不让空内容覆盖原文。

## 状态栏

`TranslatorStatusBar`（`src/statusBar.ts`）右下角显示当前 Profile 名和状态：`$(globe)` 就绪、`$(sync~spin)` 测试中、`$(check)` 成功、`$(alert)` 失败。点击触发切换。切换时用 silent 模式后台测连，只靠图标反馈，不弹通知。

## 统计

`TranslationStats`（`src/statistics.ts`）在 `enableStatsLogging` 打开时，把每次翻译的模型、Profile、字符数、耗时写到工作区的 `.vscode/translator-stats.jsonl`，一行一条 JSON。默认关。

## v0.3.1 补丁

v0.3.1 修了 v0.3.0 的几个交互问题：

- 状态栏点击报 `command 'ipynbTranslator.selectProfile' not found`：重新注册 `selectProfile`，重定向到 `manageProfiles`。
- 删除配置后 `activeProfile` 指向不存在的项：启动时 `validateActiveProfile` 检查，无效就重置到第一个。
- 缺 Key 时弹窗死循环：加 `MissingApiKeyError`，改成显示「Manage Profiles」按钮。
- 新增 `src/commands/manageProfiles.ts`，把 Switch/Add/Delete 合并成一个 QuickPick 菜单。

注：这个 QuickPick 向导在 v0.4 被 Webview 面板取代，`manageProfiles.ts` 已删除。
